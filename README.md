# 📦 Installation

Clone the repository

```bash
git clone https://github.com/manasranjanmeher99/Gemini-Project.git
```

Move into the repository

```bash
cd Gemini-Project
```

Install dependencies

```bash
pip install -r requirements.txt
```

> Each project also contains its own `requirements.txt` if needed.
